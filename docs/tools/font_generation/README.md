# Font Generation

Font Generation ist ein CLI-Tool, um Schriftarten für unser ESP-Projekt zu generieren.

## Requirements

- Python 3
- pip
- virtualenv

## Getting Started (Windows)

Abhängigkeiten installieren:

```cmd
.venv\Scripts\python.exe -m pip install .
```

Tool starten:

```cmd
.venv\Scripts\python.exe -m python font_generation.py
```
